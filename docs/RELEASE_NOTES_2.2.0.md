## 中文

本版本尚未发布；以下为开发分支更新，安装包待更新。

- 新增“投资研究”工作区，保留全流程、筛选股票和指定股票分析入口。
- 新增本地股票名称、代码与近似名称推荐。
- 修复分析卡住与失败后反复启动，支持从已保存阶段手动续跑。
- 代码修复先展示方案，确认后执行。
- 统一应用名称与资料来源说明，恢复完整共享资料与主动新闻调查。

正式下载请使用当前稳定版 [v2.1.5](https://github.com/Robertzsy/ai-trading-automation/releases/tag/v2.1.5)。支持 Windows 10/11 x64，仅用于投资研究与模拟交易。

## English

This version has not been released. These changes are on the development branch; the installer still needs updating.

- Added an Investment Research workspace, keeping full-workflow, screening and specified-stock analysis actions.
- Added local stock suggestions by name, code and approximate name.
- Fixed analysis stalls and repeated starts after failure, with manual resume from saved stages.
- Code repairs present a plan and require confirmation before execution.
- Unified the application name and source disclosures, and restored complete shared material and active news investigation.

Download the current stable build, [v2.1.5](https://github.com/Robertzsy/ai-trading-automation/releases/tag/v2.1.5). Windows 10/11 x64; investment research and paper trading only.
