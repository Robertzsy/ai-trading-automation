# AI 驱动多市场投资研究与模拟交易自动化系统 — 量化与 AI 投资逻辑

[返回首页](../README.md) · [English](INVESTMENT_LOGIC_EN.md)

AI Trading Automation 将多因子筛选、量化组合优化、多智能体研究和模拟执行连接起来。本文说明各环节的计算方法、输入输出与协作边界；具体数据可用性与来源约定见[研究数据接口说明](RESEARCH_DATA_PIPELINE.md)。

**量化回答“哪些标的值得研究、仓位如何配置”，AI 回答“投资逻辑是否成立、有哪些反证”，风控决定“这笔模拟交易是否允许执行”。**

## 1. 从数据到决策

| 环节 | 主要输入 | 方法与输出 |
|---|---|---|
| 量化筛选 | 市场发现结果、行情、历史指标 | 硬过滤、多因子评分，生成候选及筛选依据 |
| AI 个股研究 | 候选或用户指定标的、行情、财务、新闻、情绪、持仓 | 四路研究、多空辩论、研究裁决，形成逐股建议 |
| AI 组合研究 | 逐股建议、账户、策略授权书 | 组合草案、风险辩论与最终裁决，输出动作和目标权重 |
| 代码风控与模拟执行 | 决策、当前账户、引擎获取的行情、有效约束 | 生成可执行订单，模拟成交或拒绝，并保存回执 |
| 量化配置参考 | 历史价格、当前持仓、成本与配置 | 独立比较组合方案，供助手读取和解读 |

筛选得分、AI 研究判断、优化器权重和最终模拟订单是不同的结果，分别记录。用户指定股票可以直接进入研究；组合优化器的结果通过独立工具读取，固定研究工作流不会自动采用其推荐权重。

## 2. 量化筛选：用一致的规则缩小研究范围

### 2.1 过滤与预选

原生市场发现路径先归一化证券代码，再按配置检查名称排除规则、最低价格、成交额、市值、PE/PB 上限和单日涨跌幅。ST/退市等名称匹配与部分特殊证券排除规则按市场配置生效，审计记录包含各类拒绝原因计数。

通过过滤的候选先做低成本预排序，再为有限数量的候选获取详细快照并计算多因子。最终候选数量由配置限制，已有持仓同时进入研究范围。配置了固定标的池或用户直接指定股票时，入口与市场发现筛选不同，不能把它们视为通过了全部市场筛选规则。

数据源或因子不足时，结果会标明回退状态、来源和错误；没有计算出的因子分不会伪装成正常排名。

### 2.2 多因子加权评分

各因子映射到 0–100 分，默认权重如下：

| 因子 | 默认权重 | 当前计算依据 |
|---|---:|---|
| 动量 | 25% | 近 5 日和 20 日涨跌幅分别线性映射、截断后取平均 |
| 相对强度 | 20% | 20 日涨跌幅相对当次候选样本中位数的偏离映射 |
| 趋势 | 12% | 价格与 MA20/MA60 的关系、MA5/10/20 排列、MACD 柱与 RSI14 区间 |
| 放量突破 | 12% | 5 日涨跌幅与量比联合映射，避免单纯按量比放大 |
| 加速度 | 8% | 5 日与 20 日动量的差映射 |
| 风险调整动量 | 8% | 20 日收益除以近期波动率后映射 |
| 流动性 | 7% | 成交额相对当次预筛候选样本的分位 |
| 估值 | 4% | 当前 PE/PB 的绝对区间分段评分 |
| 低波动 | 4% | 近期收益波动率反向映射，分数截断到有效区间 |

综合分按权重归一化：

```text
综合分 = Σ（因子分 × 配置权重）÷ Σ（配置权重）
```

各因子按配置权重归一化加权。该分数只用于候选排序，不代表上涨概率或预期收益；潜力分与质量分还会按 55% / 45% 合成为最终候选排序。

估值项当前采用 PE/PB 绝对分段，未计算个股历史估值分位，也未做行业中性化。权重来自规则配置，并非训练所得；77 分不能解读成 77% 的上涨概率。相同数据、配置与实现下，量化评分可以复算；实时数据变化或数据回退会改变结果。

实现：[筛选引擎](../engine/screening/engine.py)。

## 3. 组合优化：从个股排序进入仓位与风险比较

优化器对齐标的共同历史交易日，计算收益均值与协方差，结合当前持仓和交易成本，比较以下方案：

| 方法 | 当前实现 | 用途 |
|---|---|---|
| 均值—方差 | 在候选权重中采样比较历史估计夏普比率 | 对照收益与波动的取舍 |
| Black–Litterman | 将由协方差、先验权重构造的均衡收益与历史均值观点融合，再搜索权重 | 比较融合先验后的配置 |
| 风险平价 | 迭代调整权重，使各资产风险贡献趋近均衡 | 对照风险集中程度 |
| 成本调整 | 根据当前持仓与目标权重估算买卖换手、佣金、税费和滑点后比较方案 | 判断调仓成本对配置选择的影响 |

输出包括风险资产权重、包含 CASH 的组合权重、历史收益与波动估计、夏普比率、调仓成本，以及样本内 VaR95、尾部平均损失、最大回撤和最差日/周/月表现。结果区分风险资产内部权重与全账户权重，保留现金配置。

收盘调度运行优化器并保存结果，投资助手可读取最新结果进行对照解读。它提供配置参考，实际调仓仍须进入决策提交和风控检查。

当前 Black–Litterman 的观点输入来自历史收益均值及配置的置信度，尚未接入大模型生成的收益预测。上述搜索与迭代属于数值近似；历史样本指标及成本估计不等于未来收益，也不能代替完整策略回测。

实现：[优化算法](../engine/optimizer/engine.py) · [数据对齐与方案比较](../engine/optimizer/runner.py)。

## 4. AI 研究：解释信号、寻找反证、形成组合建议

量化候选进入研究后，AI 结合技术面、基本面、新闻和情绪证据，审查信号背后的投资逻辑，并通过分工与辩论保留不同意见。

| 阶段 | 角色与任务 | 输出 |
|---|---|---|
| 基础研究 | 每只标的分别进行技术面、基本面、新闻、情绪研究 | 观点、证据、风险与数据质量说明 |
| 研究辩论与逐股建议 | 多头、空头论证，研究经理裁决，逐股交易员形成建议 | BUY / SELL / HOLD、目标权重、置信度和理由 |
| 组合草案 | 组合构建经理汇总逐股建议与账户约束 | 组合层面的决策草案 |
| 风险辩论 | 激进、保守、中立风险视角辩论，风险经理裁决 | 风险意见与修订决策 |
| 最终决策 | 组合经理综合研究与风险意见 | 最终决策清单与风险说明 |

角色执行数量随标的数和辩论轮数变化。例如，在默认单轮研究辩论和风险辩论下，4 只股票会展开为 38 个角色任务。

- **使用可追溯资料**：共享研究资料保留行情、财务和新闻的来源、日期、单位与缺口；可比口径下的部分派生指标由程序计算，供角色引用。
- **输出有结构**：角色通过结构化输出交接，保留观点、理由、风险和证据引用，阶段结果与原始资料分别归档。
- **研究不足时限制行动**：基础研究达到配置的完整性与引用门槛后才进入后续决策；失败持仓强制 HOLD，失败的新候选排除，整体成功比例不足则停止该轮。
- **保留反方意见**：多空与风险辩论用于暴露分歧，研究经理、风险经理与组合经理依次形成裁决。

例如，某只股票动量和量能得分较高，AI 仍需检查上涨是否得到财务或事件支持，是否存在反向证据、估值压力或不合适的入场条件，随后给出交易或观望建议。这是协作方式的示意，不代表一次真实运行或收益结果。

证据引用与结构校验提高可追溯性，不能自动证明资料真实或推理正确。AI 的置信度表达对具体判断的把握；对 HOLD 的高置信度不表示看好上涨，也不能与量化因子分直接互换。

实现：[多阶段工作流](../app/plugins/dsh-investment-tools/lib/analysis-workflow.js) · [研究数据接口](RESEARCH_DATA_PIPELINE.md)。

## 5. 风控与模拟执行：把判断转成受约束的订单

最终决策包含动作、目标权重、置信度、理由和证据引用。进入执行时，Python 引擎独立检查账户、行情与有效约束。

- **仓位与资金边界**：目标权重同时受市场与策略单票上限约束；单笔金额、总仓位、现金储备、换手和订单数量继续限制实际可交易规模。
- **保护性决策优先**：执行检查时按配置生成硬止损、移动止损、分批止盈等保护性卖出；达到最大回撤条件时，禁止新买入并生成清仓决策。
- **标的和价格校验**：决策限于允许标的池，执行参考价由引擎获取，不直接使用 AI 报出的价格。
- **按市场配置模拟撮合**：检查整手、可卖数量、T+1/T+0、涨跌停等约束，并计算佣金、税费和滑点。保护性卖出也可能因交易规则受阻，不保证触发后立即清仓。
- **可复盘的执行记录**：保存成交、拒绝原因与账户内幂等回执，防止相同提交因重试重复成交。

保守、中立、激进三档策略授权书定义不同风险预算。实际生效参数由策略选择、市场配置及兼容逻辑共同决定，应查看当前授权书和配置；不存在适用于全部市场和全部策略的统一置信度门槛。

手动研究流程默认停在等待批准；启用自主模拟调度后，可在既定授权与检查下提交模拟交易。所有路径均使用模拟账户。

实现：[策略授权书](../engine/investment/mandate.py) · [硬风控](../engine/trading/risk.py) · [模拟经纪](../engine/trading/broker.py)。

## 6. 如何理解当前能力与验证结果

本项目已实现规则筛选、量化配置比较、多智能体证据研究与模拟执行记录。它们支持复查“为何选中、为何行动或观望、为何被风控限制”，但这些能力本身不构成收益证明。

仓库还包含轻量动量规则回测，可输出收益、回撤、夏普与成本等研究指标。该模块使用简化的价格与成本模型，未重放完整的多智能体决策，也未覆盖模拟经纪的全部交易规则。

评估完整策略效果仍需明确样本期、数据时点、基准、样本外区间、交易成本与执行假设。候选评分、历史优化指标、单次研究案例和软件测试通过均不能替代这项验证。

> 本项目仅支持投资研究与模拟交易，不连接真实券商，不构成投资建议。
