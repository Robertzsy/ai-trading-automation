## 量化与 AI 如何协同

![量化筛选、AI 研究、组合和现金配置、Python 风控、模拟撮合与审计的流程示意](assets/quant-ai-workflow.zh.png)

量化高分提供研究优先级。AI 结合技术、财务、新闻和情绪材料，审查机会是否成立、反证是否足以推翻逻辑，再形成个股及组合建议。现金规则会在 AI 裁决后进一步处理动作与目标权重；所有拟执行订单仍须进入独立风控。

量化组合优化器提供独立的权重、风险和调仓成本参考，由助手读取和解读。WATCH 当前属于研究状态，执行层按 HOLD 处理，不会因触价自动下单。

## 九因子评分与候选排序

![九因子基础权重、五项进攻潜力权重和55/45排序组合](assets/quant-ai-factors.zh.png)

各因子映射到 0–100 分。基础多因子分涵盖全部九项指标；进攻潜力分侧重动量、相对强度和量价变化。

```text
基础多因子分 = Σ（因子分 × 配置权重）÷ Σ（配置权重）
进攻潜力分 = 32%×动量 + 26%×相对强度 + 16%×放量突破
           + 12%×加速度 + 14%×风险调整动量
最终排序分 = 55%×进攻潜力分 + 45%×基础多因子分
```

## 组合优化与策略参数

均值—方差、Black–Litterman、风险平价和成本调整方案分别提供配置参考，输出包含现金的权重、历史收益与波动估计、VaR95、尾部平均损失、回撤及调仓成本。Black–Litterman当前以历史均值和配置置信度构造观点，不使用AI生成的收益预测；搜索与迭代属于数值近似。

| 优化器参数 | 当前默认值 |
|---|---:|
| 回看参数 | 120日 |
| 最低共同价格观测数 | 31个，形成至少30个收益观测 |
| 单次最多标的数 | 12只 |
| 最大夏普搜索采样参数 | 3,000 |
| 年化无风险收益率假设 | 2% |
| Black–Litterman τ / 观点置信度 | 0.05 / 0.50 |
| 风险厌恶参数 / 运行时限 | 2.50 / 180秒 |
| 成本调整 | 开启 |

| 授权书参数 | 保守 | 中立 | 激进 |
|---|---:|---:|---:|
| 总仓位上限 | 55% | 75% | 95% |
| 最低现金储备 | 45% | 25% | 5% |
| 策略单票上限 | 8% | 12% | 20% |
| 单笔金额占权益上限 | 3% | 5% | 8% |
| 最低决策置信度 | 0.75 | 0.60 | 0.55 |
| 单轮换手上限 | 10% | 20% | 40% |
| 单轮最多订单 / 每日最多交易 | 2 / 4 | 3 / 6 | 5 / 10 |
| 最大回撤触发阈值 | −8% | −12% | −18% |

表中为策略授权书设定，需用户实际选择策略后结合市场配置生效。例如当前A股单票上限10%，中立策略最终单票上限为 `min(12%,10%)=10%`，且每笔仍受5%的金额上限约束。

当前程序现金部署门槛为“最低现金储备+5个百分点”，中立策略对应现金高于30%，且要求至少存在一个20日或60日预期收益为正的候选；启动后会尝试补充部署建议。当前提示词另使用现金高于25%的要求，两处口径尚不一致，不能写成统一阈值。所有部署建议都不是强制成交指令。
