# AI Trading Automation v2.2.1

## 中文

- 新增“投资研究”工作区，保留全流程、筛选股票和指定股票分析三个入口。
- 支持本地股票名称、代码与近似名称推荐。
- 修复分析卡住和失败后反复启动，支持从已保存阶段手动续跑。
- 代码修复先展示方案，确认后执行；恢复完整共享资料与主动新闻调查。
- 应用名称统一为 AI Trading Automation，保留原有数据与设置。

Windows 10/11 x64。下载 `AiTradingAutomation-Setup-x64.exe`，直接覆盖安装即可升级。校验文件为同名 `.sha256` 文件。

## English

- Added an Investment Research workspace, keeping all three analysis actions.
- Added local stock suggestions by name, code and approximate name.
- Fixed analysis stalls and repeated starts after failure, with manual resume from saved stages.
- Code repairs require a proposed plan and confirmation; restored complete shared material and active news investigation.
- Unified the application name as AI Trading Automation, preserving existing data and settings.

Windows 10/11 x64. Run `AiTradingAutomation-Setup-x64.exe` to install or upgrade in place. The matching `.sha256` file provides the checksum.
