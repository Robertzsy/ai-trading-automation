## 中文

- 点击持仓即可查看个股历史走势，支持时间范围、走势线与 K 线切换。
- 新增成本线、成交量、MA20 和模拟成交日期展示。
- 按市场与币种查看账户和组合，标明行情来源与日期。
- 首页分析用例增加图表与流程展示。

**安装**：Windows 10/11 x64，下载 [InvestmentAuto-Setup-x64.exe](https://github.com/Robertzsy/ai-trading-automation/releases/download/v2.1.5/InvestmentAuto-Setup-x64.exe)，可覆盖升级并保留已有数据。[SHA-256 校验文件](https://github.com/Robertzsy/ai-trading-automation/releases/download/v2.1.5/InvestmentAuto-Setup-x64.exe.sha256)。

本版本用于投资研究与模拟交易，不连接真实券商。

## English

- Select a holding to view its price history, with date ranges and line or candlestick views.
- Added cost basis, volume, MA20 and simulated fill dates.
- View accounts and allocation by market and currency, with data sources and dates.
- Added charts and a workflow view to the README example.

**Installation**: Windows 10/11 x64. Download [InvestmentAuto-Setup-x64.exe](https://github.com/Robertzsy/ai-trading-automation/releases/download/v2.1.5/InvestmentAuto-Setup-x64.exe) and install over the existing version, preserving user data. [SHA-256 checksum](https://github.com/Robertzsy/ai-trading-automation/releases/download/v2.1.5/InvestmentAuto-Setup-x64.exe.sha256).

For investment research and paper trading; no live broker connection.
