## 一、界面：从"能用"到"好看且看得清"

### 设计基线

- **设计令牌层**：颜色、字号、间距、圆角、阴影、动效全部收敛为令牌，不再散落字面量。新增门禁扫描自引用变量（`--ia-x: var(--ia-x)` 这类会让声明被静默丢弃的写法）。
- **固定浅色单一主题**：`color-scheme: light` 锁定，暗色分支彻底移除，不再跟随系统。
- **对比度达标**：全部文本通过 WCAG AA。修复前实测 **124 处不达标**；现在扫描 **约 490 个文本元素，0 违规**，渐变背景上的文字也按每个色标单独校验。
- **字号下限**：原来最小的正文是 **11px**，现在整体抬到 **12px**，仪表盘关键数字另行加大。

### 视觉语言

- **图标集**：14 个内置 SVG 图标，替换原先的字符占位符。
- **大圆角 + 渐变**：统一的圆角语言与品牌渐变（渐变止点已按 AA 重新选色）。
- **层级（elevation）**：四档阴影，卡片/浮层/弹窗层级明确。
- **交互状态机**：hover / active / focus / disabled 统一到一套状态定义。

## 二、分析中心

- **三个一键入口置顶**：`一键全流程` / `一键筛选股票` / `一键分析指定股票`。三者**尺寸统一（604×42）**，主操作渐变、其余描边，读作一组控件而不是三个孤立按钮。
- **删除重复按钮**：原「开始分析」与「一键分析指定股票」调用**同一个处理函数**，是一个动作渲染了两次，已移除（连带清理其孤立样式）。
- **预检清单收拢**：原来是 5 行常驻绿字，现在是**一行 40px 摘要**——「预检 5/5 就绪」或「预检 N 项未满足」，**有未满足项时自动展开**。灰掉的按钮永远说得出原因。
- **实时时间线 + 每轮报告**：轮次报告改用 **Markdown 渲染**（此前把 Markdown 语法当纯文本显示），表格数字对齐。
- **进度图形化**：阶段进度环 + 轮次进度条，动画尊重"减少动态效果"偏好。
- **轮次可停止**：见下文「引擎修复」——停止会真正中断子代理，而不只是改一个状态。

## 五、缺陷修复

### 轮次在启动阶段就死掉（`MISSING_CREDENTIAL`）

桌面端轮次失败为 `rc=1`，界面显示 `子任务 0/0 · 证据 0`——**看起来像数据丢失，实际是轮次在任何 agent 启动前就崩溃了**。

根因：引擎 bridge 只在 `IA_ACCESS_TOKEN` 非空时才加载 DPAPI 凭据补丁。**跳过补丁不是安全默认，而是最坏结果**——不打补丁时，默认的 `.credentials.yaml` provider 仍然启用、DPAPI provider 从未插入，于是**根本不存在凭据服务**。

> token 只决定**引擎是否校验**，从不该决定 **provider 是否安装**。

已修复为：bridge 生成**轮次专属补丁**（注入本次会话的真实引擎 URL 与 token），只要基础补丁存在就应用。相关测试原本**断言了缺陷行为**，已重写为回归守卫。

### 其余修复

| 问题 | 根因 |
|---|---|
| 工作流状态**永不前进** | 校验读了一个引擎从未产出过的阶段名 `execution`，导致该项永远显示"等待中"，即使轮次已完成 |
| 持仓表**每一列都错位一格** | 表头比数据行多一个单元格（市场名被放进了 `thead`），已改为 `<caption>` |
| KPI 卡右半空白 | 全宽网格单元里只有三个左对齐文本节点，无横向编排 |
| 账户面板字太小 | `--ia-fs-micro` 为 11px 且用在恰好最需要读清的那些标签上 |
| 停止轮次后仍显示运行中 | 取消时未收尾运行中的 agent 行；迟到的事件被忽略 |
| Windows 上原子写偶发失败 | 固定长度临时名在 `os.replace` 上触发共享冲突（`WinError 5/32/33`） |
| MongoDB 未配置时拖慢启动 | 可选依赖改为**快速、安静且明确**地失败 |
| 轮次跑在**别人的 DSH home** | 不再信任继承来的 `DSH_HOME`，改为识别"是否是本产品的数据根" |

## 七、已知限制

1. **无法构建安装包**：本机未安装 Inno Setup（ISCC），因此本轮改动只能以源码/热更新方式分发，未产出安装程序或便携包。
2. **模型选择未持久化**：`storages/settings.json` 缺失，轮次回退到 `config.yaml` 的默认模型。
3. **桌面端 `.env` 存有旧 API key**：生产链路因 DPAPI 补丁而**不受影响**，但这是一个静默陷阱——若某次启动绕过补丁，会用到旧 key。
4. **外壳的一处边界**：`ProcessManager.cs` 用 `??` 兜底生成 token，空字符串不会触发。引擎侧的修复已完全覆盖这个边界，但彻底修好需要重新编译外壳。
